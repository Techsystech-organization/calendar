1. Navigate to **Calendar > Configuration > Booking Types**.
2. Open the booking type you want to publish.
3. In the **Website** section, check **Published on Website**.
4. Optionally customize the **Website Slug** (auto-generated from the name).
5. Optionally add a **Website Description** that will appear on the booking page.
6. The booking page is now accessible at `/book/<slug>`.
